# Imagens do site

Este diretório armazena todas as imagens do site da Estofaria Capital.

## Estrutura

```text
assets/images/
├── logo/                   → Logotipo
│   └── logo-gl.svg
├── hero/                   → Imagens do Hero (fundos de tela cheia)
│   └── hero-01.jpg
├── empresa/                → Fotos da empresa / profissionais
│   └── sobre-01.jpg
├── servicos/               → Fotos das seções de serviços
├── antes-depois/           → Projetos antes/depois
│   ├── projeto-01/         → antes.jpg, depois.jpg
│   ├── projeto-02/
│   ├── projeto-03/
│   └── projeto-04/
├── portfolio/              → Trabalhos realizados
│   ├── sofa/
│   ├── poltrona/
│   ├── cadeira/
│   ├── banco/
│   └── outros/
└── estudio/                → Fotos do estúdio/processo de trabalho
    ├── tecido-01.jpg
    ├── tecido-02.jpg
    ├── tecido-03.jpg
    └── tecido-04.jpg
```

## Recomendações

- Utilize imagens comprimidas (JPG otimizado ou WebP para melhor performance).
- Mantenha a proporção de 16:9 para imagens do Hero.
- As fotos antes/depois devem ter o mesmo enquadramento para melhor comparação.
